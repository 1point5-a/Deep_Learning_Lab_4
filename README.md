# Deep Learning Lab

A collection of Jupyter notebooks from a Deep Learning lab course, covering foundational concepts implemented from the ground up.

## Contents

| Notebook | Description |
|---|---|
| [`Single_Layered_Perceptron.ipynb`](./Single_Layered_Perceptron.ipynb) | Implementation of a single-layer perceptron, covering the core building blocks of neural networks — weights, bias, activation function, and the learning rule. |
| [`Additional_Tasks_lab1.ipynb`](./Additional_Tasks_lab1.ipynb) | Supplementary exercises extending the concepts from the first lab. |

## Getting Started

### Prerequisites

- Python 3.x
- Google Colab or Jupyter Notebook
- Common data science libraries, typically:
  - `numpy`
  - `matplotlib`
  - `pandas`

Install dependencies with:

```bash
pip install numpy matplotlib pandas jupyter
```

### Running the Notebooks

1. Clone the repository:
   ```bash
   git clone https://github.com/1point5-a/Deep-Learning-Lab.git
   cd Deep-Learning-Lab
   ```
2. Open any `.ipynb` file and run the cells in order.
